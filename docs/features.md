# 功能細節


**Bot**
- 左側抽屜是 Bot 清單，新安裝時只有一個「pi」。新增 Bot 時挑頭像（12 個像素頭像）、取名字、寫「工作」說明，例如「每天整理我的行程，早上 8 點給我簡報」；這段說明一直放在它的系統提示裡，它也知道還有哪些其他 Bot。最多 12 個。
- 每個 Bot 只有一條對話，沒有「新對話」或分支。對話超過門檻時自動壓縮成摘要（設定 › 自動壓縮：64k、128k、256k（預設）、512k 或模型上限）；也可以手動壓縮。
- 從 Bot 的面板或清單上的「⋯」改名字、工作、頭像，看它的記憶，清空它的資料夾，或刪除它（先停下它正在做的事，再刪掉它的記憶、排程、附件和資料夾；至少留一個）。刪到一半 app 被關掉、或電腦連不上而容器裡的資料夾刪不掉，下次打開 app 會接著刪。pi-durable 還不能刪除一條對話，所以對話紀錄只是不再顯示，仍留在手機的資料庫裡。
- 天氣：這裡或任何地點（宜蘭、合歡山、東京）的現況、逐小時與 16 天預報，來自 Open-Meteo（免費、不用 key）。「等等會下雨嗎」「週六去宜蘭要帶傘嗎」會拿預報的數字回答。
- 地點：附近的加油站、咖啡廳、藥局，或依名稱找分店（最近的全聯），來自 OpenStreetMap（Photon 搜尋、Nominatim 補營業時間與電話），免費、不用 key。OSM 沒有評分，要挑好的時 Bot 會再用網路搜尋，並用路線工具算實際時間。
- 資料庫：手機上一個 SQLite 資料庫，所有 Bot 共用。Bot 自己建表、記錄、查詢：「幫我記帳：午餐 150」「這個月花了多少」。設定 › 資料庫可以看資料表與筆數，或匯出整個 .db 檔。
- MCP：設定 › MCP › 瀏覽服務，從精選的服務（Notion、Linear、Todoist、Stripe、Sentry、Context7……）一鍵連接，或直接輸入網址；需要登入的在瀏覽器完成 OAuth（自動註冊、PKCE、本機跳轉網址，token 存在 Keystore），新加的服務不會給任何 Bot（即使和以前移除的服務同名），在服務下面或 Bot 面板的「連接的服務」選哪些 Bot 可以用；移除服務會一併收回所有 Bot 的使用權並關閉連線。服務的工具需要時才載入（tool_search），平常不佔提示。工具執行前不會問你，選哪些 Bot 可以用就是授權。
- 通知讀取（設定 › 通知讀取，開一次系統權限）：其他 App 的通知（LINE、Messenger、信件、外送…）在手機上留 30 天，開了「通知」工具的 Bot 就能回答「剛剛誰找我」「有沒有要處理的」。聊天通知逐則記錄，含發話者；只看得到通知裡顯示的內容。
- Bot 面板的「工具」可以逐組開關這個 Bot 能用的工具：網路、天氣、地點、手機狀態、手機 App、日曆、通知、資料庫、語音、GitHub、Google Cloud、Cloudflare、Azure、電腦、程式模式。關掉的工具模型看不到，程式模式的腳本也呼叫不到。手機的日常工具常駐；電腦、GitHub 和三家雲端需要時才載入（tool_search），面板上每組標出常駐或需要時載入、約佔多少 tokens；還沒在設定裡連接的顯示「尚未設定」。記憶、skills 和排程一直開著。執行中的 Bot 有閃爍標記。
- OpenAI 可以用 **Sign in with ChatGPT**：在瀏覽器用 ChatGPT 帳號登入，改用訂閱、不需要 API key；模型清單只列訂閱能用的那些。
- 模型和思考強度選單，依供應商分組，每個模型標出 context 長度、能不能看圖、支不支援思考。模型和規格來自 pi-ai 的目錄；自訂端點的模型取自它的 `/v1/models`，認得的模型（例如 gateway 轉發的 Claude、GPT）也套用目錄的規格。
- Agent 工作時可以「插話」（插到下一輪工具之後）或「稍後」（等這次跑完）。排隊的訊息可以撤回；按停止時，排隊的訊息會放回輸入框。
- 點自己的訊息可以複製。
- 上下文用量和 token 統計。
- Markdown 回答、程式碼區塊一鍵複製、思考過程可以收合；工具步驟即時顯示輸出和經過秒數。

**輸入**
- **附件**：輸入框的迴紋針可以選照片，或 PDF、Word（docx）、Excel（xlsx）、CSV 和純文字檔。檔案在手機上轉成文字，不經過 sandbox 或任何伺服器（做法見 `docs/research/attachments.md`）：
  - 小檔案整份放進訊息；大檔案只放開頭，Bot 用 `read_attachment` 讀其他段落、指定頁數或搜尋。
  - PDF 每頁標頁碼。沒有文字的頁面（掃描檔）在手機上 OCR（ML Kit，中英文），讀起來、搜尋起來跟一般頁面一樣；OCR 也讀不出字的頁面（照片、手寫）才轉成圖片。問到圖表或版面時 Bot 會自己把頁面轉成圖片。
  - **掃描文件**：迴紋針 › 掃描文件，或跟 Bot 說「幫我掃一下這份合約」，打開系統的掃描畫面（自動找邊、拉平），掃完變成 PDF 附件。
  - 試算表每個工作表匯入資料庫成一張表，Bot 用 `sql` 計算，而不是自己加總。送出前移除附件，匯入的表也會刪掉。
  - 照片、`view_photos` 看的照片、PDF 頁面裡的 QR code 和條碼，在手機上解碼後連同圖片交給模型（WebView 的 `BarcodeDetector`）。模型自己看圖解不出 QR；沒有條碼時不多花任何 token。
  - 附件存在手機上（IndexedDB），刪除 Bot 時一起刪掉；匯入資料庫的表留著，跟其他資料表一樣在「設定 › 資料庫」。
- 文字、圖片，以及**語音**：輸入框是空的時候，送出鈕會變成麥克風。用系統的語音辨識（繁體中文），結果放進輸入框讓你確認後再送。

**背景執行**
- 有對話在跑時，前景服務加 wake lock 讓 app 不被凍結，通知列顯示「pi 工作中」，鎖上螢幕也會繼續跑。
- App 不在前景時，跑完會通知「pi 完成了」。

**記憶（MEMORY.md）**
- **全域記憶**：每個 Bot 都該知道的事：家和公司在哪、家人、飲食、喜歡的回答方式。所以「回家要多久」「上班要多久」不用每次說地址。在「設定 › 全域記憶」編輯。
- **Bot 的記憶**：只跟那個 Bot 的工作有關的事，例如研究員記得你在追哪些主題。從 Bot 的「⋯」編輯。
- 你提到家在哪、不吃什麼時，agent 會用 `update_memory` 自己記下或更新，並選擇記在全域還是自己的記憶；步驟上看得到改了什麼（例如 `memory 家：板橋府中站附近 → 新店`）。
- 存在手機上，但每次請求都會放進系統提示送到模型供應商，所以不要放密碼或金鑰。每份上限 4000 字。

**排程與觸發**：agent 可以在你開口之前自己動起來。設計見 [design/triggers.md](design/triggers.md)。
- `create_schedule`：「每天早上 8 點給我早晨簡報」這類重複或一次性的排程。排程屬於建立它的 Bot，到時間就在那個 Bot 的對話裡跑，所以它看得到前幾天的結果。
- `schedule_followup`：agent 自己排「10 分鐘後再看一次部署」，結果接在同一條對話後面。
- **其他事件**：「開始充電時」「連上公司 Wi‑Fi 時」「到家時」「離開公司時」「收到媽媽的 LINE 時」「收到含『入帳』的通知時」「解鎖手機時」「電量低時」「換時區時」「拍了新照片時」「車用藍牙連上或斷開時」「上車、下車、開始走路時」，一樣可以限定星期幾、時段和最多多久一次。地點和指定 Wi‑Fi 名稱要把 pi 的位置權限設成「一律允許」；通知要開「通知讀取」，通知的 app、寄件人和內容會一起交給 agent。解鎖和電量低只有 pi 在執行時收得到，開了通知讀取 pi 會一直在背景；照片要「相片」權限，藍牙裝置要「鄰近裝置」，活動要「體能活動」。
- **戴上耳機時**：「平日早上第一次戴上耳機時，用語音跟我匯報今天的工作事項」。藍牙耳機（A2DP，只算耳機類的裝置；車用音響、免持套件、喇叭不算）連上時觸發，pi 沒在執行也收得到；有線耳機只在 pi 執行中時認得。可以限定星期幾、時段，和最多多久一次（「一天一次」是每天第一次戴上時）。Android 12 起要允許「鄰近裝置」權限，建立時會問。
- `speak`：用手機的文字轉語音念給你聽，從耳機出來，其他聲音會暫時調小。拿下耳機就停。開口前 agent 會先讀 `spoken-report` 技能（`src/agent/skills/spoken-report.md`）：先講結論，最多三件、每件一個下一步，約一分鐘，不唸單號、網址和查詢過程；細節和連結留在文字回覆。
- `notify`：由 agent 判斷結果值不值得通知你，沒有新東西就不發。
- **健康資料**：「我這週睡得怎樣」「今天走幾步」，讀 Health Connect 的步數、心率、睡眠、運動、體重（Android 14 起系統內建）。用 Samsung Health 記錄的，要在 Samsung Health › 設定 打開「同意處理健康和保健資料」，Health Connect 也要允許存取；它從那之後的資料開始同步，回到 Samsung Health 主畫面會觸發一次。
- **叫出 pi 看目前畫面**：在「設定 › 手機 › 系統權限」把 pi 設成數位助理，長按側邊鍵就能在任何畫面叫出 pi。系統把當下的截圖和畫面上的文字交給 pi，放進上次用的 Bot 的輸入框，你再說要做什麼。只有你叫出 pi 時它才看得到畫面。
- **分享給 pi**：在其他 app 按「分享」選 pi，文字、連結、照片或檔案（可以一次好幾個）會放進 Bot 的輸入框，由你說要做什麼。檔案跟用迴紋針選的一樣處理。有多個 Bot 時先問你要交給哪一個。
- 設定頁的「排程」標明每個排程屬於哪個 Bot，可以暫停、立即執行、刪除。每個排程一天最多跑 10 次，全部加起來 30 次。
- 到時間時：pi 還在背景執行中，就直接在背景跑完；pi 已經被系統清掉，就先跳一則「點一下開始」的通知，點了會打開那個 Bot 並自動執行。
- Chromium 會凍結隱藏超過一分鐘的頁面（計時器和外掛回呼全部停住）。agent 工作時，`PiWebView` 對 Chromium 回報視窗可見，讓頁面繼續跑；工作結束後恢復真實狀態。
- 用精確鬧鐘準時觸發。Android 14 起新安裝的 app 預設沒有這個權限，設定頁會提示開啟；已經設成「不受電池最佳化限制」時不需要。

**工具**
- `web_search`：用模型供應商本身的搜尋（優先用自訂端點，其次 OpenAI、Anthropic）：OpenAI Responses 的 `web_search`，或 Anthropic 的 `web_search` server tool，不需要另外的搜尋 API key。`web_fetch`：從手機抓網頁並轉成文字。
- **手機的狀態與感測器**：每次只在 agent 呼叫時讀一次，不在背景追蹤。
  - `device_info`：電量、充電、省電模式、網路（Wi-Fi 或行動網路、VPN）、鈴聲模式、勿擾、連接的耳機、剩餘空間。
  - `get_location`：位置和地址（Android 內建的地址反查，不需要 API key）。只要「使用 app 時」的定位權限。
  - `read_sensors`：氣壓和估算海拔、指南針方位、環境光、距離感測。
  - `get_travel_time`：開車、走路、腳踏車的距離和時間，用 OpenStreetMap 的路線服務（[FOSSGIS 的公開 OSRM](https://routing.openstreetmap.de)，免費、不需要 key）。地址用手機內建的 geocoder 轉成座標。開車時間不含路況，也沒有大眾運輸。
- `github_api`、`github_read_file`：從手機直接呼叫 GitHub REST API。
- **交給手機上的其他 app**：
  - `read_calendar_events`、`list_calendars`、`add_calendar_event`：讀行程、新增活動。設定頁的「行事曆」可以**按帳號**決定：
    - **讀取**：關掉的帳號 agent 完全看不到，行程也不會送到模型供應商。適合不想讓公司行程送出去的情況。
    - **寫入**：只有打開的帳號能新增活動，可以設一個預設行事曆。
    - **分享的行事曆**（訂閱的同事、團隊、節日行事曆）：預設不讀，打開後也只在你問起時讀，並標明是別人的；永遠不能寫入。
  - `compose_email`、`compose_sms`：打開草稿，由你按「傳送」。
  - `open_maps`：打開 Google Maps 的路線。
  - `open_link`：用對應的 app 打開網址或 deep link（`geo:`、`tel:` 只開撥號畫面、`spotify:` 等）。
  - `share`：打開分享選單，可以把 sandbox 裡的檔案（圖表、PDF）傳到 LINE、Drive 等。
  - `set_alarm`、`set_timer`：直接設定鬧鐘和計時器，不開時鐘 app。
  - Android 不允許背景的 app 打開其他 app，所以 pi 在背景時這些工具會失敗，並請你回到 pi。
- **Code mode**：模型可以寫 JavaScript，在一個腳本裡批次呼叫工具（`tools.<name>(args)`）、整理資料。腳本在手機上的 QuickJS VM 裡跑，VM 放在 Web Worker 裡，所以不會卡住 UI；每個結果都先記下來，app 被殺掉後會接著跑。
- 電腦上的 `read`、`write`、`edit`、`bash`，見[架構](architecture.md)。

**工作區**
- 瀏覽 Bot 的資料夾——在手機上，或在電腦上（例如 `/workspace/pi`）——看檔案（行號、Markdown 預覽、圖片），電腦上還有每個 git repo 的變更、diff 和最近的 commit。
- **HTML 成果**：請 Bot 做報告、比較表、圖表、小工具，它會寫成一個 `.html` 檔；在工作區打開就是預覽（在隔離的框裡跑，碰不到 app、沒有網路），右上角「分享」把檔案傳到 LINE、email、Drive 或存到裝置。設計見 `docs/design/artifacts.md`。
- Agent 用 `read` 讀回來的圖片（圖表、轉檔後的照片）會直接顯示在對話裡；工具步驟上的檔案圖示會在工作區打開那個檔案，code mode 或 bash 的輸出提到 `.html` 時也有。

**操作**
- Android 返回手勢依序關閉最上層的畫面；什麼都沒開時，app 退到背景，不會被關掉。
- 在對話上任何地方往右滑拉出 Bot 清單，往左滑拉出目前這個 Bot 的面板（也可以按左上角的 pi 和右上角的「⋯」）：面板跟著手指走，放開時拉過四成或用力一甩就打開，否則彈回；在打開的面板上往回滑就收起來。跟 Discord 一樣不必從邊緣開始，所以不會跟系統的返回手勢（從邊緣滑進來）衝突。從輸入框開始的滑動不算，那裡是提示詞轉盤。
- Bot 的面板：工作說明、排程（可以暫停、立即執行、刪除）、記憶、sandbox 資料夾、上下文用量和壓縮。
