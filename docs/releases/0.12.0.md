pi mobile 0.12.0：每個 Bot 有自己的瀏覽器，會替你開網頁、點按鈕、填表單，要登入時交給你。

> **非官方社群專案**：pi mobile 不是 [pi](https://pi.dev) 官方產品，與 Earendil 沒有關聯，也沒有經過他們背書。問題請回報到這個 repo。

## 下載
- **手機**：已經裝了 0.9.1 以後的版本，到設定頁最下面按「更新到 0.12.0」就好。也可以下載 `pi-mobile-0.12.0.apk` 手動安裝，**Android 16 以上**、arm64 手機；用同一把金鑰簽章，可以直接覆蓋安裝，保留現有資料。
- **iPhone**：從 TestFlight 更新。瀏覽器這一版只有 Android 有。
- **電腦**：跟 0.10.0 一樣，沒有變。還沒更新到 0.10.0 的話：
  ```sh
  curl -fsSL https://raw.githubusercontent.com/geminixiang/pi-mobile/main/host/install.sh | sh
  ```

## 這一版有什麼
- **Bot 的瀏覽器**：在 Bot 的工具組打開「瀏覽器」，Bot 就能自己開網頁、看內容、點按鈕、輸入中英文、選下拉選單、上一頁。比對商品、查訂位、填表單這類要動手的事，可以直接交代它。
- **看得到它在做什麼**：Bot 用瀏覽器時，畫面上方會滑下一張瀏覽器，做完自己收起來。也可以從標題列往下拉，或按標題列的地球圖示打開，用網址列自己上網；往上推或按下面的橫條收起。
- **要登入時交給你**：遇到登入、驗證碼、付款，Bot 會停下來請你接手，你處理完按「交還」，它再接著做。登入會留著，下次不用再登。手機的密碼自動填入（Google 密碼管理工具、Samsung Pass）也能用。
- **每個 Bot 各自一個**：Bot 之間的登入和 cookie 分開，刪掉 Bot 時它的瀏覽資料一起刪掉。一個 Bot 最多開 4 個分頁，Bot 要看幾個網頁時會同時載入。
- **搜尋引擎**：設定 › 瀏覽器 可以選 DuckDuckGo（預設）或 Google，網址列打關鍵字就用它搜尋。

## 要注意
- **0.9.0 以前的版本**：還沒有 App 內更新，要先手動裝一次 0.9.1 或這一版。
- **手機畫面**：更新 app 後，Android 會把無障礙服務關掉，要到 設定 › 手機 › 手機畫面 再開一次。
- **Bot 不會替你打密碼**：要輸入密碼、付錢、送出或刪除東西之前，Bot 會先說它要做什麼。
