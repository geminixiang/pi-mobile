pi mobile 0.9.2：設定首頁的每一項都有了圖示。

> **非官方社群專案**：pi mobile 不是 [pi](https://pi.dev) 官方產品，與 Earendil 沒有關聯，也沒有經過他們背書。問題請回報到這個 repo。

## 下載
- **手機**：已經裝了 0.9.1 的話，到設定頁最下面按「更新到 0.9.2」就好。也可以下載 `pi-mobile-0.9.2.apk` 手動安裝，**Android 16 以上**、arm64 手機；用同一把金鑰簽章，可以直接覆蓋安裝，保留現有資料。
- **電腦**：跟 0.9.0 一樣，沒有變。還沒更新到 0.9.0 的話：
  ```sh
  curl -fsSL https://raw.githubusercontent.com/geminixiang/pi-mobile/main/host/install.sh | sh
  ```

## 這一版有什麼
- **設定的圖示**：模型、全域記憶、帳號、連接的服務、電腦、手機、自動化、資料庫，每一列前面都有圖示，一眼就找得到。新圖示取自 Lucide；全域記憶和電腦沿用 Bot 面板和抽屜原本的圖示，同一件事在各處長得一樣。

## 要注意
- **0.9.0 以前的版本**：還沒有 App 內更新，要先手動裝一次 0.9.1 或這一版。
- **手機畫面**：更新 app 後，Android 會把無障礙服務關掉，要到 設定 › 手機 › 手機畫面 再開一次。
