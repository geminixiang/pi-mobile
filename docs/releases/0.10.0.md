pi mobile 0.10.0：側欄改成把對話推開、跟著手指走；字級和間距重新整理，淺色重新配色；Bot 能刪日曆活動；電腦端只讓你自己的其他裝置進來，移除配對時它開著的指令一起結束。

> **非官方社群專案**：pi mobile 不是 [pi](https://pi.dev) 官方產品，與 Earendil 沒有關聯，也沒有經過他們背書。問題請回報到這個 repo。

## 下載
- **手機**：已經裝了 0.9.1 以後的版本，到設定頁最下面按「更新到 0.10.0」就好。也可以下載 `pi-mobile-0.10.0.apk` 手動安裝，**Android 16 以上**、arm64 手機；用同一把金鑰簽章，可以直接覆蓋安裝，保留現有資料。
- **電腦**（選用，macOS 或 Linux，要裝好 Tailscale）：電腦端這一版有更新，跑同一行就會更新，配對和權限都保留：
  ```sh
  curl -fsSL https://raw.githubusercontent.com/geminixiang/pi-mobile/main/host/install.sh | sh
  ```

## 這一版有什麼
- **側欄**：打開時整個對話往旁邊推開，側欄本來就在底下；從任何一列都能往旁邊滑，畫面跟著手指走，放開後一定停在全開或全關，不會停在一半。滑的第一格不再跳一下。
- **字級和間距**：字級從 22 種收成 9 種，各有固定用途；中文字不再加字距；邊距和間隔都對齊 4 px 的格線。
- **淺色**：淺色模式的顏色照 pi 的系統主題的算法，用這個 app 自己的顏色重新算過；程式碼區塊改成整排寬的色帶，跟工具列一樣；背景格線淡一點。
- **自動化**：清單裡每一列平常只顯示名稱、什麼時候跑、選了哪些防線和上次的結果；點那一列才展開防線、「立即執行」和「刪除」。
- **日曆和鬧鐘**：
  - Bot 能刪日曆活動。重複的活動預設只刪那一次，你要求才刪整個系列。
  - 在 Android 上新增活動會失敗的問題修好了；沒有狀態的活動，讀日曆時也會出現。
  - 時鐘的鬧鐘 app 改不了，Bot 會打開鬧鐘清單讓你自己刪；手機畫面開著時，它可以在那個畫面幫你刪。
- **App 內更新**：按「更新到…」直接進系統的安裝畫面，不會先跳出其他能開 APK 的 app 讓你選。
- **電腦連線**（要電腦端也更新到 0.10.0）：
  - 電腦只接受同一個 Tailscale 帳號的**其他**裝置；電腦上的其他程式不能自己配對，借用你給 pi-mobile 的 macOS 權限。
  - 在電腦上執行 `pi-mobile devices` 列出配對過的裝置，`pi-mobile unpair <名稱>`（或 `--all`）刪掉；它開著的指令 5 秒內結束。手機遺失時用這個。
  - 從手機移除電腦、或配對被刪時，Bot 在電腦上跑的指令會一起結束，不再留著繼續跑。
  - 配對在電腦上被刪掉後，設定 › 電腦 會在那台下面顯示配對碼欄位，輸入新的配對碼就能重新配對。

## 要注意
- **電腦的位址要是 Tailscale 的**：手機只連 `*.ts.net`、Tailscale IP（`100.x`）或 MagicDNS 短名稱。以前填成區網 IP 或 `mac.local` 的電腦會連不上，請改成 Tailscale 的名稱。
- **電腦端也要更新**：上面電腦連線的修正，要電腦端是 0.10.0 才有。舊的電腦端配新的手機可以用。
- **0.9.0 以前的版本**：還沒有 App 內更新，要先手動裝一次 0.9.1 或這一版。
- **手機畫面**：更新 app 後，Android 會把無障礙服務關掉，要到 設定 › 手機 › 手機畫面 再開一次。
