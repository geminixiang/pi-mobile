pi mobile 0.9.3：手機上的名字改成「Pi」。

> **非官方社群專案**：pi mobile 不是 [pi](https://pi.dev) 官方產品，與 Earendil 沒有關聯，也沒有經過他們背書。問題請回報到這個 repo。

## 下載
- **手機**：已經裝了 0.9.1 以後的版本，到設定頁最下面按「更新到 0.9.3」就好。也可以下載 `pi-mobile-0.9.3.apk` 手動安裝，**Android 16 以上**、arm64 手機；用同一把金鑰簽章，可以直接覆蓋安裝，保留現有資料。
- **電腦**：跟 0.9.0 一樣，沒有變。還沒更新到 0.9.0 的話：
  ```sh
  curl -fsSL https://raw.githubusercontent.com/geminixiang/pi-mobile/main/host/install.sh | sh
  ```

## 這一版有什麼
- **名字**：桌面圖示、多工畫面，以及 Android 設定裡的應用程式列表、通知存取、無障礙，都顯示「Pi」。Bot 請你到 Android 設定開權限時，說的路徑也跟著改成「設定 › 應用程式 › Pi」。

## 要注意
- **在 Android 設定裡找「Pi」**：以前叫「pi mobile」的地方，更新後都叫「Pi」。
- **0.9.0 以前的版本**：還沒有 App 內更新，要先手動裝一次 0.9.1 或這一版。
- **手機畫面**：更新 app 後，Android 會把無障礙服務關掉，要到 設定 › 手機 › 手機畫面 再開一次。
