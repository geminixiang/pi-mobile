pi mobile 0.4.0：自動化觸發時，先讓一個小模型判斷要不要叫醒 Bot；廣告、驗證碼、想操控 AI 的訊息會先被擋下。

> **非官方社群專案**：pi mobile 不是 [pi](https://pi.dev) 官方產品，與 Earendil 沒有關聯，也沒有經過他們背書。問題請回報到這個 repo。

## 下載
- **手機**：`pi-mobile-0.4.0.apk`，Android 7.0 以上、arm64 手機。用同一把金鑰簽章，可以直接覆蓋安裝 0.3.0。
- **電腦**（選用，macOS 或 Linux，要裝好 Tailscale）：
  ```sh
  curl -fsSL https://raw.githubusercontent.com/geminixiang/pi-mobile/main/host/install.sh | sh
  ```
  已經裝過的話，跑同一行就會更新。

## 這一版有什麼
- **防線**：通知、照片這類事件觸發自動化時，先交給 Jev 這類 classifier 回答幾個是非題，不符合就不叫醒 Bot，也不算進每天的次數。內建四組，在自動化那一列直接勾：
  - **擋 AI 指令**：訊息想叫 AI 忽略指示、交出資料或執行指令（prompt injection）
  - **擋驗證碼**：一次性驗證碼、密碼、API key，不會被送進聊天模型
  - **擋廣告**：促銷、優惠券、群發訊息
  - **只要需處理的**：你本人需要回覆或處理的才叫你

  通知的自動化預設勾前兩個。內建的不夠時，Bot 可以再寫一個自己的是非題，例如「訊息是家人傳的嗎？」。被擋下時，那一列會寫理由，例如「略過：廣告（95%）」。
- 在 S24 上連發五則通知：廣告、銀行驗證碼、想騙出 API key 的訊息、外送送達都被各自的防線擋下，只有媽媽問「晚餐回家吃嗎？」叫醒了 Bot。
- **不再跳出提示框**：操作的結果和錯誤直接顯示在你按的地方，例如「壓縮中…」「已複製」，其他的錯誤寫在對話最後。
- 對話捲到頂欄和輸入框底下時，文字會淡出，不再被硬切。

## 要注意
- **防線要一把 classifier 的 key**：在設定 › 模型 › 新增供應商加 OpenRouter、TypeSafe、Cloudflare 或 Vercel AI Gateway。OpenRouter 的 key 可以限制成只能用 Jev。一次判斷約 0.00002 美元。沒有 key 時自動化照常執行，Bot 會被告知內容沒有檢查過。
- Jev 偶爾忙不過來（回 529），重試後還是失敗時，有勾「擋」的自動化會先略過那一次（「無法判斷，先擋下」）。
- 照片的防線目前只看文字（相簿和檔案），還沒看圖片內容。
