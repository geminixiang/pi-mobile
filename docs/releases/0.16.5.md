pi mobile 0.16.5：電腦上的指令可以在背景跑完再通知你；讀到想指揮 Bot 的內容後，要送出東西前會先問你。

> **非官方社群專案**：pi mobile 不是 [pi](https://pi.dev) 官方產品，與 Earendil 沒有關聯，也沒有經過他們背書。問題請回報到這個 repo。

## 下載
- **手機**：已經裝了 0.9.1 以後的版本，到設定頁最下面按「更新到 0.16.5」就好。也可以下載 `pi-mobile-0.16.5.apk` 手動安裝，**Android 16 以上**、arm64 手機；用同一把金鑰簽章，可以直接覆蓋安裝，保留現有資料。
- **iPhone**：從 TestFlight 更新。
- **電腦**：不用更新。

## 這一版有什麼
- **背景跑指令**：跟選了電腦的 Bot 說「在 Mac 上跑測試，好了跟我說」，指令會在電腦上背景跑，Bot 馬上回你，你可以繼續聊別的；跑完它會自己回報結果。手機睡著也不影響。
- **送出前先問你**：Bot 讀到電腦上的 agent 畫面裡有想指揮它的文字時，對話裡會出現提醒卡；接下來它要交辦可能有害、又不是你要的工作，會先問你「送出這次」或「不要」，你同意才送，而且只送那一次。
- **管電腦上的 agent 更穩**：agent 的選項在你看過之後變了，Bot 不會照舊的號碼回答；排程叫醒時不會替你批准；同一個畫面不會一直重複讀。
- **設定頁看得到版本**：設定頁最下面先寫版本號，再寫程式版本和建置時間。

## 修正
- **字忽然變小**：Bot 的回答後面接著選項按鈕時，那段回答以前會變成小的灰字，現在跟一般回答一樣大。

## 要注意
- **送出前先問你**：目前只用在電腦上的 agent，網頁、通知、簡訊這些還沒接上。判斷要用 Jev（OpenRouter 上的 TypeSafe 分類模型）；沒有設定時，讀過外部內容後交辦一律先問。
- **背景指令**：預設在 Bot 在電腦上的資料夾裡跑；跑完一天後紀錄會清掉。現在還不能從手機停掉一個正在跑的指令。
- **代你操作 App**：更新 app 後，Android 會把無障礙服務關掉，要到 設定 › 手機 › 代你操作 App 再開一次。
