pi mobile 0.7.0：Bot 能看手機畫面、替你操作任何 app；電腦改成要配對碼才接受連線。

> **非官方社群專案**：pi mobile 不是 [pi](https://pi.dev) 官方產品，與 Earendil 沒有關聯，也沒有經過他們背書。問題請回報到這個 repo。

## 下載
- **手機**：`pi-mobile-0.7.0.apk`，Android 7.0 以上、arm64 手機。用同一把金鑰簽章，可以直接覆蓋安裝 0.6.0，保留現有資料。
- **電腦**（選用，macOS 或 Linux，要裝好 Tailscale）：
  ```sh
  curl -fsSL https://raw.githubusercontent.com/geminixiang/pi-mobile/main/host/install.sh | sh
  ```
  已經裝過的話，跑同一行就會更新。

## 這一版有什麼
- **手機畫面**：新的工具組，Bot 能看手機上任何 app 的畫面，替你開 app、點、長按、滑、捲動、打字、返回。例如「用計算機算…」「設定裡 One UI 版本是多少」「時鐘裡有哪些鬧鐘」「在三星筆記新增一則筆記」。
  - 要先打開：設定 › 手機 › 手機畫面 › 開啟，會跳到 Android 的無障礙設定。從網路下載安裝的 APK，開關可能是灰的，要先到 App 資訊 › ⋮ › 允許受限制的設定。
  - Bot 預設只讀畫面上的文字和按鈕，需要時才看截圖；實測五個工作比一律附截圖少 28% 的 tokens。
  - 不想讓某個 Bot 用，在 Bot 面板關掉「手機畫面」。
- **電腦要配對**：電腦上的 `pi-mobile` 只接受用配對碼配對過的手機。以前同一台手機上的其他 app 也連得到電腦、能在上面執行指令。
- **金鑰不走未加密的連線**：自訂供應商、網路搜尋、連接的服務（MCP）的金鑰，只會經由 https、Tailscale 或本機送出；設成區網的 `http://` 位址時會直接拒絕，不帶金鑰的服務（例如區網的 Ollama）照常可用。
- **修正**：選了電腦容器的 Bot，準備容器時畫面不再一直重繪。

## 要注意
- **更新後電腦要重新配對**：在電腦上跑上面那行更新指令（或 `pi-mobile pair`），它會印出 6 位數配對碼（15 分鐘內有效）；手機到 設定 › 電腦，在那台電腦旁的欄位輸入。配對前，Bot 連不到那台電腦。
- **手機畫面**：
  - 更新 app 後，Android 會把無障礙服務關掉，要再開一次。
  - 和其他工具一樣不會先問你：Bot 被要求送出、付款、刪除、發文之前會先說它要做什麼，除非你要它做的就是這件事。
  - 畫面上的文字會送給你設定的模型，密碼欄只顯示 `••••`；禁止截圖的 app（例如銀行）只看得到文字和按鈕。
