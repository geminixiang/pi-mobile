pi mobile 0.16.3：通知看得懂了，也有自己的聲音。

> **非官方社群專案**：pi mobile 不是 [pi](https://pi.dev) 官方產品，與 Earendil 沒有關聯，也沒有經過他們背書。問題請回報到這個 repo。

## 下載
- **手機**：已經裝了 0.9.1 以後的版本，到設定頁最下面按「更新到 0.16.3」就好。也可以下載 `pi-mobile-0.16.3.apk` 手動安裝，**Android 16 以上**、arm64 手機；用同一把金鑰簽章，可以直接覆蓋安裝，保留現有資料。
- **iPhone**：從 TestFlight 更新。
- **電腦**：不用更新。

## 這一版有什麼
- **通知說重點**：Bot 做完事，通知顯示它的頭像、名字和回答的重點，點一下就開到那個 Bot。不再只寫「pi 完成了」。
- **問題直接寫出來**：Bot 在等你回答，通知會顯示問題和選項；服務要你填資料時，也會顯示它問什麼。
- **pi 的聲音**：做完是木頭輕敲，等你回覆和主動通知是敲門，一聽就知道。iPhone 還是系統聲音。
- **排程開始**：點「點一下開始」的通知，會開到那個 Bot。

## 要注意
- **通知設定**：為了換聲音，通知頻道換新了，你之前對「pi 完成」「pi 主動通知」的個別設定要重新調一次。
- **代你操作 App**：更新 app 後，Android 會把無障礙服務關掉，要到 設定 › 手機 › 代你操作 App 再開一次。
