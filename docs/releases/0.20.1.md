pi mobile 0.20.1：整理自訂供應商的連線方式，為之後支援更多 gateway 做準備；使用上和 0.20.0 一樣。

> **非官方社群專案**：pi mobile 不是 [pi](https://pi.dev) 官方產品，與 Earendil 沒有關聯，也沒有經過他們背書。問題請回報到這個 repo。

## 下載
- **手機**：已經裝了 0.9.1 以後的版本，到設定頁最下面按「更新到 0.20.1」就好。也可以下載 `pi-mobile-0.20.1.apk`（或永遠指向最新版的 `pi-mobile.apk`）手動安裝。需要 **Android 16 以上**、arm64 手機。安裝檔用同一把金鑰簽章，可以直接覆蓋安裝，保留現有資料。
- **iPhone、iPad**：從 TestFlight 更新。
- **電腦**：這一版不用更新。

## 這一版有什麼
- **自訂供應商的「轉接器」**：pi 連自訂端點時，一律先用標準的 API；認出是特定的 gateway（目前是 CLIProxyAPI）時，才改用那個 gateway 專屬、更省流量的連線方式，出問題就退回標準方式。各家 gateway 的特殊做法放在各自的轉接器裡，之後要支援別家，不會動到其他人的連線。
- 使用上沒有變化：0.20.0 的「只上傳新增的部分」和「請求先壓縮」照舊。

## 要注意
- **代你操作 App**：更新 App 後，Android 會把無障礙服務關掉，要到 設定 › 手機 › 代你操作 App 再開一次。
