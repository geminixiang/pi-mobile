pi mobile 0.6.0：附件可以直接拍照，Bot 的資料夾移到右上角，手機 git 能檢查 diff 和看物件。

> **非官方社群專案**：pi mobile 不是 [pi](https://pi.dev) 官方產品，與 Earendil 沒有關聯，也沒有經過他們背書。問題請回報到這個 repo。

## 下載
- **手機**：`pi-mobile-0.6.0.apk`，Android 7.0 以上、arm64 手機。用同一把金鑰簽章，可以直接覆蓋安裝 0.5.0，保留現有資料。
- **電腦**（選用，macOS 或 Linux，要裝好 Tailscale）：
  ```sh
  curl -fsSL https://raw.githubusercontent.com/geminixiang/pi-mobile/main/host/install.sh | sh
  ```
  已經裝過的話，跑同一行就會更新。

## 這一版有什麼
- **拍照**：附件選單第一項是「拍照」，打開系統相機，拍完直接附在訊息裡。pi 不需要相機權限。
- **資料夾在右上角**：Bot 有資料夾（手機上或電腦上）時，標題列的「…」旁邊多一個資料夾 icon，一點就打開。Bot 資訊面板只留下容器的「清空資料夾」。
- **手機 git 的檢查指令**：資料夾的 bash 支援 `git diff --check`（含 `--cached`、`--staged` 與 `-- <路徑>`），以及 `git cat-file -t`、`-s`、`-p`。
- **按鈕變成 icon**：複製回答、程式碼區塊的複製、檔案檢視器的複製／分享／用其他 app 開啟、安裝指令的分享／複製、「再試一次」都改成 icon；複製後 icon 變成勾兩秒。
- **修正**：停用中的按鈕按下去不再亮起；輸入框取得焦點時的外框不再被蓋掉。連接電腦時逐欄檢查電腦回報的資訊，格式不對會說哪一欄，不再帶著錯的資料繼續。

## 要注意
- 拍的照片暫存在 app 自己的 `Pictures/`，超過一天的會在 pi 啟動時刪掉。
- `git cat-file` 還不支援 `<rev>:<path>`、`--batch` 與 `-e`；`git diff --check` 不檢查還沒 `git add` 的新檔案。
