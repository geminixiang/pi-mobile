pi mobile 0.13.0：Bot 會替你記住還沒了結的事，到時間或對方一回覆就自己回來處理；桌面小工具列出今天輪到你的事；手機也能指揮電腦上的 coding agent。

> **非官方社群專案**：pi mobile 不是 [pi](https://pi.dev) 官方產品，與 Earendil 沒有關聯，也沒有經過他們背書。問題請回報到這個 repo。

## 下載
- **手機**：已經裝了 0.9.1 以後的版本，到設定頁最下面按「更新到 0.13.0」就好。也可以下載 `pi-mobile-0.13.0.apk` 手動安裝，**Android 16 以上**、arm64 手機；用同一把金鑰簽章，可以直接覆蓋安裝，保留現有資料。
- **iPhone**：從 TestFlight 更新。
- **電腦**：跟 0.10.0 一樣，沒有變。還沒更新到 0.10.0 的話：
  ```sh
  curl -fsSL https://github.com/geminixiang/pi-mobile/releases/latest/download/install.sh | sh
  ```

## 這一版有什麼
- **事項**：跟 Bot 說「週五前要繳費」「我在等房東回覆」，它會記成一筆事項，所有 Bot 共用一份，只存在手機上。到了該再看的時間，負責的 Bot 會自己醒來處理，需要你時通知你；事情真的了結才結案。問「還有哪些事沒處理」就會列出來。
- **對方一回就知道**：在等的回覆會以通知出現在手機上（簡訊、LINE、Gmail…）時，Bot 會設好條件，對方一回就叫醒它，告訴你重點；輪到你決定的事會改成「要做」。要先開「通知讀取」（設定 › 手機）。
- **桌面小工具：輪到你**：沒有新匯報時，小工具列出今天到期、已經過期或沒有時間的待辦，點一行打開負責的 Bot。
- **匯報小工具改版**：一次一則填滿整個小工具，右邊一長條按下一則；沒有新東西時是一間 Bot 在打盹的小房間。打開那個 Bot 後，它的匯報就會收掉。
- **排程更準時**：時間到就跑，不再先詢問。允許 pi「顯示在其他應用程式上層」的話，pi 被滑掉後排程也會在背景安靜啟動、準時執行，不用點通知。
- **通知**：標題是 Bot 的名字，打開那個 Bot 後通知就收掉；pi 在背景時，Bot 的通知也會確實跳出來。
- **電腦上的 coding agent**：選了電腦的 Bot，可以列出電腦上用 Herdr 或 Rex 跑的 coding agent（例如 Claude Code），看它在做什麼、交辦工作；做完、卡住要你核准、或關掉時，Bot 會被叫醒告訴你，核准也能在手機上回答。在「電腦上的 agent」工具組開關。
- **網頁來源**：回答裡引用的網頁，來源會標在那句話後面。
- **步驟更好讀**：瀏覽器和手機畫面的步驟各一行；失敗時寫「第 N 步 X 失敗：原因」，不再貼出整頁內容。

## 修正
- **打開手機畫面時當機**：從設定開手機畫面，改成打開無障礙清單，不再閃退。
- **刪掉的 Bot 的匯報**：刪掉 Bot 後，它留在小工具上的匯報會一起拿掉。
- **瀏覽器一打開就捲動**：剛開好網頁就捲動不會再失敗。

## 要注意
- **事項和「輪到你」只有 Android**：iPhone 這版還沒有小工具。
- **對方回覆要 pi 在背景**：通知要 pi 還在跑才收得到；通知讀取開著時 pi 會留在背景，從最近使用的 App 滑掉就可能聽不到。寄到電腦的信收不到，要靠事項的時間去追。
- **0.9.0 以前的版本**：還沒有 App 內更新，要先手動裝一次 0.9.1 或這一版。
- **手機畫面**：更新 app 後，Android 會把無障礙服務關掉，要到 設定 › 手機 › 手機畫面 再開一次。
