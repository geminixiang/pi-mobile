pi mobile 0.11.2：修正定時任務跑完卻沒有通知；修正 0.11.0 起，模型的腳本有時只執行到一半。

> **非官方社群專案**：pi mobile 不是 [pi](https://pi.dev) 官方產品，與 Earendil 沒有關聯，也沒有經過他們背書。問題請回報到這個 repo。

## 下載
- **手機**：已經裝了 0.9.1 以後的版本，到設定頁最下面按「更新到 0.11.2」就好。也可以下載 `pi-mobile-0.11.2.apk` 手動安裝，**Android 16 以上**、arm64 手機；用同一把金鑰簽章，可以直接覆蓋安裝，保留現有資料。
- **電腦**：跟 0.10.0 一樣，沒有變。還沒更新到 0.10.0 的話：
  ```sh
  curl -fsSL https://raw.githubusercontent.com/geminixiang/pi-mobile/main/host/install.sh | sh
  ```

## 修正
- **腳本只執行到一半**：0.11.0 加入「腳本忘了寫 `return` 時，自動回傳最後一行」，但最後一行寫了好幾個步驟時，會在第一個步驟就結束，後面的步驟沒有執行，例如發通知。0.11.0、0.11.1 都有這個問題，請盡快更新。
- **定時任務跑完沒通知**：
  - 只要 pi 開在前景就不發通知，即使畫面停在別的 Bot 或設定頁。現在只有正在看同一個對話時才不發。
  - 排程的指示寫了要通知時，模型一律通知；之前它會自己判斷「沒有新內容」而略過。

## 要注意
- **0.9.0 以前的版本**：還沒有 App 內更新，要先手動裝一次 0.9.1 或這一版。
- **手機畫面**：更新 app 後，Android 會把無障礙服務關掉，要到 設定 › 手機 › 手機畫面 再開一次。
