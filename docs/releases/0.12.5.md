pi mobile 0.12.5：左右側欄滑開、關上時有震動回饋；瀏覽器面板的上一頁、下一頁和網址列按了馬上有反應，切換 Bot 時面板不會再自己打開；Bot 給的步驟有缺漏時，會在動手前就停下來。

> **非官方社群專案**：pi mobile 不是 [pi](https://pi.dev) 官方產品，與 Earendil 沒有關聯，也沒有經過他們背書。問題請回報到這個 repo。

## 下載
- **手機**：已經裝了 0.9.1 以後的版本，到設定頁最下面按「更新到 0.12.5」就好。也可以下載 `pi-mobile-0.12.5.apk` 手動安裝，**Android 16 以上**、arm64 手機；用同一把金鑰簽章，可以直接覆蓋安裝，保留現有資料。
- **iPhone**：從 TestFlight 更新。
- **電腦**：跟 0.10.0 一樣，沒有變。還沒更新到 0.10.0 的話：
  ```sh
  curl -fsSL https://raw.githubusercontent.com/geminixiang/pi-mobile/main/host/install.sh | sh
  ```

## 這一版有什麼
- **側欄滑動時有震動**：手指放開、左右側欄確定要打開時震一下，確定要關上時輕震一下；滑到一半退回原狀不會震。

## 修正
- **瀏覽器面板的按鈕馬上有反應**：上一頁、下一頁、重新整理和網址列不再先等幾秒才動。
- **切換 Bot 不會再打開面板**：在一個 Bot 打開過瀏覽器面板後，切到別的 Bot 或切回來，面板不會自己跳出來。
- **步驟有缺漏時先停下來**：Bot 操作網頁或手機畫面時，只要有一步缺了該給的內容，整串步驟一步都不會做，Bot 會直接知道哪一步有問題，不會做到一半才失敗。
- **回到 pi 時讀得對**：Bot 在手機畫面按了主畫面再打開 pi，現在會正確讀到 pi 已經在前面。

## 要注意
- **0.9.0 以前的版本**：還沒有 App 內更新，要先手動裝一次 0.9.1 或這一版。
- **手機畫面**：更新 app 後，Android 會把無障礙服務關掉，要到 設定 › 手機 › 手機畫面 再開一次。
