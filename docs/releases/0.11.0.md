pi mobile 0.11.0：Mermaid 圖表換成更小、照螢幕寬度排版的 pele；右側欄和底部面板改版；模型知道每則訊息的時間；較弱的模型用工具更穩；修掉一個閒置耗電的問題。

> **非官方社群專案**：pi mobile 不是 [pi](https://pi.dev) 官方產品，與 Earendil 沒有關聯，也沒有經過他們背書。問題請回報到這個 repo。

## 下載
- **手機**：已經裝了 0.9.1 以後的版本，到設定頁最下面按「更新到 0.11.0」就好。也可以下載 `pi-mobile-0.11.0.apk` 手動安裝，**Android 16 以上**、arm64 手機；用同一把金鑰簽章，可以直接覆蓋安裝，保留現有資料。
- **電腦**：跟 0.10.0 一樣，沒有變。還沒更新到 0.10.0 的話：
  ```sh
  curl -fsSL https://raw.githubusercontent.com/geminixiang/pi-mobile/main/host/install.sh | sh
  ```

## 這一版有什麼
- **Mermaid 圖表**：
  - 改用 [pele](https://pele.run) 繪製。圖表照螢幕寬度排版，橫的流程圖會自動改成直的，長條圖縮到螢幕寬，字不會變小。
  - Mermaid 內建的圖表類型都能畫，例如甘特圖、時間軸、心智圖、圓餅圖。
  - 圖表的程式少了一半。
  - 圖裡的連結和外部圖片不會載入。
- **右側欄**：
  - 「上下文」移到最上面，「現在壓縮」「新的上下文」一打開就看得到。
  - 工具和連接的服務各收成一列，點進去才是開關清單。
  - 電腦改成點一下開選單。
  - 拿掉一格一格的框線。
- **底部彈出的面板**：多了拖曳把手和正式的標題，清單不再一列一個框。
- **上下文快滿時**：對話最後會出現「上下文 82% · 壓縮」，點一下就壓縮。
- **Bot 頭像**：拿掉深藍底色和外框。
- **模型知道時間**：每則訊息都帶著送出的時間，問「現在幾點」「半小時後」不用先查手機時間，快 2–5 秒。
- **較弱的模型更會用工具**：
  - 腳本忘了寫 `return` 時，自動回傳最後一行的值。
  - 腳本什麼都沒回傳時，會告訴模型原因。
  - 參數填錯時，會列出可以填的值。

  在本地跑的 Qwen3.6 35B A3B 上，10 個常見問題從 751 秒、3 題答錯或卡住，變成 226 秒全部完成。
- **新 Bot 預設用手機資料夾**：配對電腦後，預設不再自動改成電腦的直接模式。已經在用電腦的 Bot 不受影響，想讓新 Bot 預設用電腦，到 設定 › 電腦 › 預設 選。

## 修正
- **閒置耗電**：對話畫面開著時，捲動鈕的轉盤即使沒打開，也每 60 毫秒喚醒一次。修正後 Galaxy S24 前景閒置時，WebView 的 CPU 用量約減半。0.10.0、0.10.1 都有這個問題。

## 要注意
- **0.9.0 以前的版本**：還沒有 App 內更新，要先手動裝一次 0.9.1 或這一版。
- **手機畫面**：更新 app 後，Android 會把無障礙服務關掉，要到 設定 › 手機 › 手機畫面 再開一次。
