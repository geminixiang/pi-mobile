pi mobile 0.4.2：回答裡指向檔案的連結不再把 app 帶走。

> **非官方社群專案**：pi mobile 不是 [pi](https://pi.dev) 官方產品，與 Earendil 沒有關聯，也沒有經過他們背書。問題請回報到這個 repo。

## 下載
- **手機**：`pi-mobile-0.4.2.apk`，Android 7.0 以上、arm64 手機。用同一把金鑰簽章，可以直接覆蓋安裝 0.4.1。
- **電腦**（選用，macOS 或 Linux，要裝好 Tailscale）：
  ```sh
  curl -fsSL https://raw.githubusercontent.com/geminixiang/pi-mobile/main/host/install.sh | sh
  ```
  已經裝過的話，跑同一行就會更新。

## 這一版有什麼
- Bot 在回答裡放一個指向它資料夾檔案的連結（例如 `[報告](報告.html)`）時，點下去會在檢視器打開那個檔案。之前 WebView 會導向 `http://localhost/報告.html`，整個 app 變成「網頁無法使用」，要按返回才回得來。
