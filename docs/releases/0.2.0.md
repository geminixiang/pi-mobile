pi mobile 0.2.0：從單一對話變成一群 Bot，並且能用手機本身的資料和功能。

> **非官方社群專案**：pi mobile 不是 [pi](https://pi.dev) 官方產品，與 Earendil 沒有關聯，也沒有經過他們背書。問題請回報到這個 repo。

## 下載
- `pi-mobile-0.2.0.apk`：Android 7.0 以上、arm64 手機。用同一把金鑰簽章，可以直接覆蓋安裝 0.1.0。

## 這一版有什麼
- **Bot**：多個 Bot，各有頭像、工作說明、記憶（MEMORY.md）、工具組和資料夾；左右側欄滑動切換。
- **手機能力**：通知、簡訊、通話紀錄、聯絡人、相簿、行事曆、Health Connect、螢幕使用時間、天氣、附近地點、鬧鐘與計時器、媒體、勿擾、語音播報、掃描文件。
- **排程**：定時，或在耳機連上、開始充電、連上 Wi‑Fi、到達或離開地點時執行。
- **資料**：所有 Bot 共用的 SQLite 資料庫，可匯出。
- **連接的服務**：MCP 伺服器與服務目錄；Google Cloud、Cloudflare、Azure、GitHub 不需要 sandbox 也能呼叫；工具按需載入。
- **模型**：pi-ai 內建的供應商、用 ChatGPT 登入。
- **Sandbox**：用 SSH 連自己的 Mac 或 Linux（容器或直接模式）；沒有 sandbox 時，每個 Bot 也有手機上的資料夾和 bash。
- **核准**：可以要求指紋；同一個 repo 或雲端服務的連續寫入，可以一次允許 10 分鐘。
- **設定**：一改就生效；切換 sandbox 時會告訴你切到哪台。
- 附件（PDF、Word、Excel）、從其他 App 分享給 pi、Mermaid 圖表、更順的串流與捲動。
