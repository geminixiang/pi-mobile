pi mobile 0.2.0：從單一對話變成一群 Bot，能用手機本身的資料和功能，也能把你的電腦交給它。

> **非官方社群專案**：pi mobile 不是 [pi](https://pi.dev) 官方產品，與 Earendil 沒有關聯，也沒有經過他們背書。問題請回報到這個 repo。

## 下載
- **手機**：`pi-mobile-0.2.0.apk`，Android 7.0 以上、arm64 手機。用同一把金鑰簽章，可以直接覆蓋安裝 0.1.0。
- **電腦**（選用，macOS 或 Linux，要裝好 Tailscale）：
  ```sh
  curl -fsSL https://raw.githubusercontent.com/geminixiang/pi-mobile/main/host/install.sh | sh
  ```
  它會從這個 release 下載 `pi-mobile`。之後的版本也是跑同一行來更新。

## 這一版有什麼
- **Bot**：多個 Bot，各有頭像、工作說明、記憶（MEMORY.md）、排程、工具組和資料夾，各自一條延續的對話，太長時自動壓縮。左右側欄滑動切換。
- **手機能力**：通知、簡訊、通話紀錄、聯絡人、相簿、行事曆、Health Connect、螢幕使用時間、天氣、附近地點、鬧鐘與計時器、媒體、勿擾、語音播報、掃描文件。
- **排程**：定時，或在耳機連上、開始充電、連上 Wi‑Fi、到達或離開地點時執行。
- **資料**：所有 Bot 共用的 SQLite 資料庫，可匯出。
- **你的電腦**：在 Mac 或 Linux 上跑一行指令裝好 `pi-mobile`，手機透過 Tailscale 連過去，不用 SSH、金鑰或密碼。
  - **直接**：Bot 以你的身分操作那台電腦，指令優先，網站用 ego-browser；macOS 上也能看畫面、用滑鼠鍵盤。
  - **容器**：在電腦上的 Linux 容器裡工作，GitHub 和雲端的憑證留在手機上。
  - macOS 上它是一個 app，權限在安裝時一次問完，更新後會保留。
- **連接的服務**：MCP 服務目錄，登入在瀏覽器完成；Google Cloud、Cloudflare、Azure、GitHub 從手機直接呼叫。
- **模型**：pi-ai 內建的供應商、自訂端點，或用 ChatGPT 訂閱登入。
- **程式模式為主**：模型用腳本一次呼叫多個工具，每次請求只帶少數工具定義，token 用量約是以前的三分之一。
- 附件（PDF、Word、Excel）、從其他 App 分享給 pi、Mermaid 圖表、更順的串流與捲動；設定一改就生效。

## 要注意
- **Bot 做事不會先問你**：push、改雲端資源、回覆訊息、改行事曆都直接執行。只給 Bot 你放心讓它用的工具和權限，見[安全模型](https://github.com/geminixiang/pi-mobile/blob/main/docs/security.md)。
- 0.1.0 的 SSH 連線方式已經拿掉，電腦請改用上面的安裝指令加入。
