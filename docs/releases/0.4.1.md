pi mobile 0.4.1：修正舊訊息裡工具方塊的上緣被切掉。

> **非官方社群專案**：pi mobile 不是 [pi](https://pi.dev) 官方產品，與 Earendil 沒有關聯，也沒有經過他們背書。問題請回報到這個 repo。

## 下載
- **手機**：`pi-mobile-0.4.1.apk`，Android 7.0 以上、arm64 手機。用同一把金鑰簽章，可以直接覆蓋安裝 0.4.0。
- **電腦**（選用，macOS 或 Linux，要裝好 Tailscale）：
  ```sh
  curl -fsSL https://raw.githubusercontent.com/geminixiang/pi-mobile/main/host/install.sh | sh
  ```
  已經裝過的話，跑同一行就會更新。

## 這一版有什麼
- 對話往上捲到比較早的訊息時，兩個相連的工具方塊（例如 `script` 底下接 `memory`），第二個的上緣會被切掉 12 px，標題貼著邊。現在跟上面那個一樣留白。
