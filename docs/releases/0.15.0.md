pi mobile 0.15.0：設定、Bot 面板和對話頂端整個改版，頁面跟著手指滑；網路斷了 Bot 會等網路回來再接著答；電腦端也要更新一次。

> **非官方社群專案**：pi mobile 不是 [pi](https://pi.dev) 官方產品，與 Earendil 沒有關聯，也沒有經過他們背書。問題請回報到這個 repo。

## 下載
- **手機**：已經裝了 0.9.1 以後的版本，到設定頁最下面按「更新到 0.15.0」就好。也可以下載 `pi-mobile-0.15.0.apk` 手動安裝，**Android 16 以上**、arm64 手機；用同一把金鑰簽章，可以直接覆蓋安裝，保留現有資料。
- **iPhone**：從 TestFlight 更新。
- **電腦**：這一版要更新，在電腦上執行同一行：
  ```sh
  curl -fsSL https://github.com/geminixiang/pi-mobile/releases/latest/download/install.sh | sh
  ```

## 這一版有什麼
- **對話頂端**：Bot 和工具變成兩顆浮在對話上的膠囊。點頭像開 Bot 清單，點名字換模型，名字旁的圈是用掉多少上下文；Bot 在做事時名字後面有閃爍的游標。
- **設定改版**：設定首頁分成「Bot 怎麼想」「Bot 能用什麼」「這支手機」三組，每一行第二行直接寫現在的狀態。模型、帳號、電腦、手機、顯示等頁都改成一行一行的清單，點一行打開它的細節，移除放在最後。
- **Bot 面板改版**：在哪裡執行、上下文用量、今天的自動化、記憶、工具各一行。上下文可以展開看對話、系統提示、記憶、工具各占多少。工具改成分組的圖示格，點一下開關。
- **頁面跟著手指走**：設定、記憶、工作區、檔案都能像側邊欄一樣用手指滑回上一層；從哪一邊進來，就往哪一邊退回去。
- **記憶像一篇筆記**：一條一行，按「編輯」整篇直接改，存不了會留在編輯畫面並說明原因。
- **自動化清單**：依下一次執行時間分成今天、之後、遇到時、暫停、跑完了，暫停、執行、刪除收進點開後的細節。
- **桌面小工具「待辦」**：每件事寫明幾點到期或已過期；點一件打開它的 Bot，可以請 Bot 處理、標成完成，或改到明天早上。
- **確認框**：改成跟 iPhone 一樣的置中提示框，會刪東西的按鈕是紅色。
- **震動**：只在手指按住或手勢生效時震動，例如長按 Bot、複製成功、把面板往下滑掉；單純點一下不震動。

## 修正
- **網路斷了，回答停在一半**：開著 Tailscale 這類 VPN 時，Wi-Fi 斷了連線只是卡住，回答會一直停著。現在沒資料超過一分鐘、或網路一斷，就會等網路回來再重新回答，沒網路時不會白白重試。重答前的半截回答只留一行「網路斷了，重新回答」。
- **開著 VPN 卻沒網路**：關掉 Wi-Fi 和行動數據、只剩 Tailscale 時，pi 會知道其實沒網路，等網路回來再送。
- **電腦連線**：沒網路時顯示「等網路中」，網路一回來或回到 pi 就立刻接回。
- **串流時往上捲會被拉回底部**：現在只有你自己的手指捲動才會離開底部，回答內容變短時也不會跳走。
- **連接的服務登不進去**：放在 Cloudflare Access 後面的服務，按「登入」沒反應。現在會打開它的登入頁。
- **照片還在轉檔時離開 Bot**：照片不會再不見，回來時還在輸入框或草稿裡。
- **電腦端漏掉最後一段輸出**：直接在電腦上跑的指令，結束前的最後一段輸出可能收不到。
- **中文粗體**：Android 上原本只有英文字變粗，中文現在也是粗體。

## 要注意
- **電腦的安裝指令換了網址**：改成從 release 下載（上面那一行）。舊的那一行之後會裝到跟執行檔不同版的腳本，請改用新的。
- **0.9.0 以前的版本**：還沒有 App 內更新，要先手動裝一次 0.9.1 或這一版。
- **代你操作 App**：更新 app 後，Android 會把無障礙服務關掉，要到 設定 › 手機 › 代你操作 App 再開一次。
