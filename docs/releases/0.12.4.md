pi mobile 0.12.4：Bot 操作網頁和手機畫面時，看得出每個按鈕屬於哪一項、點到了什麼，打字後會確認欄位真的存了，捲到底也會知道。

## 下載
- **手機**：已經裝了 0.9.1 以後的版本，到設定頁最下面按「更新到 0.12.4」就好。也可以下載 `pi-mobile-0.12.4.apk` 手動安裝，**Android 16 以上**、arm64 手機；用同一把金鑰簽章，可以直接覆蓋安裝，保留現有資料。
- **iPhone**：從 TestFlight 更新。
- **電腦**：跟 0.10.0 一樣，沒有變。還沒更新到 0.10.0 的話：
  ```sh
  curl -fsSL https://raw.githubusercontent.com/geminixiang/pi-mobile/main/host/install.sh | sh
  ```

## 這一版有什麼
- **看得出按鈕屬於哪一項**：清單裡每一項都有「刪除」這類同名按鈕時，Bot 會看到每個按鈕屬於哪一項，瀏覽器和手機畫面都一樣。
- **回報點到了什麼**：Bot 每點一下或打一次字，都會知道實際碰到的是哪個元素、屬於哪一項，事後查得到它做了什麼。
- **打字後確認**：在手機畫面上打完字，Bot 會讀回欄位內容；欄位沒存成它打的字（例如只收數字的欄位），會停下來說欄位顯示什麼。
- **捲到底會知道**：手機畫面捲動或點擊後畫面完全沒變，Bot 會知道捲到底了或那一下沒有作用，不會一直白捲。
- **等畫面真的變了才讀**：手機畫面每一步之後，先等畫面開始變化再讀，比較不會讀到點下去之前的舊畫面。點了沒反應的那一步，會多等約 1 秒。

## 要注意
- **你叫 Bot 刪東西時**：測試中 Bot 偶爾會多刪一項，而且不一定會說。刪重要的東西時，看一下它回報點了什麼。
- **0.9.0 以前的版本**：還沒有 App 內更新，要先手動裝一次 0.9.1 或這一版。
- **手機畫面**：更新 app 後，Android 會把無障礙服務關掉，要到 設定 › 手機 › 手機畫面 再開一次。
