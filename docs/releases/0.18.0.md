pi mobile 0.18.0：連不上模型時會等它回來再接著做；新增連線圖和「能做什麼」；回答下面多了一點就送的建議回覆；iPad 和摺疊機有自己的工作台版面；Bot 能操作 Windows 和 Linux 電腦，看畫面先讀文字、不靠截圖。

> **非官方社群專案**：pi mobile 不是 [pi](https://pi.dev) 官方產品，與 Earendil 沒有關聯，也沒有經過他們背書。問題請回報到這個 repo。

## 下載
- **手機**：已經裝了 0.9.1 以後的版本，到設定頁最下面按「更新到 0.18.0」就好。也可以下載 `pi-mobile-0.18.0.apk` 手動安裝。需要 **Android 16 以上**、arm64 手機。安裝檔用同一把金鑰簽章，可以直接覆蓋安裝，保留現有資料。
- **iPhone、iPad**：從 TestFlight 更新。
- **電腦**：**要更新**。
  - Mac、Linux：在終端機再跑一次安裝指令。
  - Windows：**這一版開始支援**，在 PowerShell 執行：
    ```powershell
    iex ([Text.Encoding]::UTF8.GetString((iwr -useb https://github.com/geminixiang/pi-mobile/releases/latest/download/install.ps1).Content))
    ```
    要先裝 [Git for Windows](https://git-scm.com/download/win)，Bot 的指令用 Git Bash 跑。

## 這一版有什麼
- **連不上模型時會等，不會放棄**：模型在 Tailscale 裡、Tailscale 暫時關掉這類狀況，以前重試幾次就停下來，要你打「Continue」。現在 Bot 會等模型回來，接著把事情做完。
  - 標題列會寫「連不上模型 · 幾點起」。
  - 對話裡只留一行「連不上模型，連回來會自動繼續」，接回後變成「已接回」。
- **連線圖**：Bot 面板最上面是「模型 ← 手機 → 電腦」的圖。
  - 有資料在跑時，線上會流動，旁邊標出實際的流量。
  - 斷線時那段線會斷開。
  - 點模型、手機、電腦，各自打開它的設定：模型和思考強度、手機的網路、通知和背景執行、電腦和「在哪裡跑」。
- **能做什麼**：Bot 面板按用途列出這個 Bot 能做的事，分成行程、訊息、生活、手機、上網、檔案與電腦、帳號與服務。
  - 整組都還沒開的，畫成虛線框的「＋」。
  - 點一組可以開關它的工具，下面有「試試看」，點了直接問 Bot。
- **建議回覆**：Bot 交出草稿、計畫或點子時，回答下面會出現一兩個「↳」按鈕，例如「↳ 改短一點」，點一下就送出。
- **核准前一定看得到內容**：Bot 問你要不要寄出、張貼、刪除時，完整的內容直接顯示在問題卡上。不會再發生只寫進檔案、你看不到就被問要不要送的情況。
- **每天早上的簡報**：新建的 Bot 第一次聊天時，會問要不要每天早上給你簡報。答應後：
  - 早上 8 點送簡報；
  - 下午 1 點、6 點各看一次，有事才通知你；
  - 晚上 11 點到早上 8 點不打擾。
  
  已經有的 Bot 不會突然問你。
- **iPad 和摺疊機的工作台**：螢幕夠寬時改成三欄：
  - 左邊一條 Bot 頭像列；
  - 中間是對話；
  - 右邊是工作台。舞台先放要你處理的事，例如等你核准的信，再來是正在跑的工作，或你打開的成果；托盤放其他工作。
  
  草稿和成果留在舞台上：點一段說「這句拿掉」，改完會標出改了哪裡，旁邊就能核准寄出。iPad 直放、摺疊機會改成上下排，手機的樣子不變。
- **操作 Windows 和 Linux 的畫面**：以前只有 Mac。
  - Bot 看畫面時先讀視窗裡的按鈕和文字，看不懂才截圖，所以更省、也點得更準。
  - 點擊和打字盡量直接對元件操作，不搶你的滑鼠和前景視窗。
  - 中文 Windows 的注音輸入法不會卡字。
  - 有好幾個螢幕也看得到、點得到。
  - Mac 打字改用貼上，不會被自動修正。
- **長指令自動轉到背景**：Bot 在電腦上跑的指令超過 10 秒就轉到背景，你可以繼續聊，跑完它會回報。
  - 輸入框上方會列出正在跑的指令，有停止按鈕。
  - 長按可以偷看目前的輸出。
- **Windows 上的 Herdr**：Windows 版 Herdr 裡的 coding agent，Bot 也能列出、看畫面、交代工作。
- **按起來更像 App**：手指一碰到，按下的顏色就出現，整列一起變色。抽屜裡的清單、選中的項目、側欄都重新整理過，不再有左邊的色條。

## 修正
- **自動執行不再有每天的次數上限**：以前所有自動執行一天合計 30 次，用完了，連你在等的工作（指令跑完的回報、到期的事項）都延到隔天。現在照排程和事件本身的頻率跑。
- **手機和電腦斷線重接時，輸入的順序不會亂**：重接那一瞬間，送到電腦的輸入可能插隊，現在已修正，並加上一個窮舉所有情況的檢查。
- **iPhone 問「我在哪」會卡住**：定位、聯絡人、相片的工具在 iPhone 上檢查權限時會一直等，現在會正常回答。
- **中文 Windows 的亂碼**：電腦回給 Bot 的中文以前是亂碼，現在是正確的中文。
- **iPhone 編輯記憶後整個 App 放大**：已修正。

## 要注意
- **代你操作 App**：更新 App 後，Android 會把無障礙服務關掉，要到 設定 › 手機 › 代你操作 App 再開一次。
- **電腦要一起更新**：看畫面的新方式、背景指令和多螢幕都需要新版的電腦端。手機更新後，記得也在電腦上重跑安裝指令。
- **iPad 的工作台**：手機和 iPad 上的 Bot 是各自的一份，還不會同步。
