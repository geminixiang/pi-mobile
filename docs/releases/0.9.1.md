pi mobile 0.9.1：之後的新版直接在 app 裡更新。

> **非官方社群專案**：pi mobile 不是 [pi](https://pi.dev) 官方產品，與 Earendil 沒有關聯，也沒有經過他們背書。問題請回報到這個 repo。

## 下載
- **手機**：`pi-mobile-0.9.1.apk`，**Android 16 以上**、arm64 手機。用同一把金鑰簽章，可以直接覆蓋安裝 0.9.0，保留現有資料。
- **電腦**：跟 0.9.0 一樣，沒有變。還沒更新到 0.9.0 的話：
  ```sh
  curl -fsSL https://raw.githubusercontent.com/geminixiang/pi-mobile/main/host/install.sh | sh
  ```

## 這一版有什麼
- **App 內更新**：GitHub 上有新版時，設定頁最下面會出現「更新到 <版本>」。按下去會下載新版的 APK，確認它跟 GitHub 公布的 SHA-256 一樣、是 pi mobile、和手機上這版用同一把金鑰簽章，才交給 Android 安裝；不對就不安裝，並在同一個地方說原因。資料都會保留。
- **README 的截圖換新**：Bot 列表、台股分析、Bot 的自動化，以及用手機控制睡前和早上的設定。

## 要注意
- **這一版要手動裝**：0.9.0 還沒有 App 內更新，所以 0.9.1 要從這裡下載安裝一次；之後的版本就能在 app 裡更新。
- **第一次在 app 裡更新**：Android 會要你允許 pi mobile 安裝應用程式。允許後回到 pi mobile，再按一次「更新到 <版本>」。
- **自己建的開發版**：用 debug keystore 簽的開發版和正式版金鑰不同，App 內更新會擋下來，說明「用不同的金鑰簽章」；要先移除再安裝，手機上的資料會一起刪掉。
- **手機畫面**：更新 app 後，Android 會把無障礙服務關掉，要到 設定 › 手機 › 手機畫面 再開一次。
