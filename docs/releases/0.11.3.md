pi mobile 0.11.3：模型填參數的小錯直接接受，不用再重試；bash 找得到剛寫的檔案。

> **非官方社群專案**：pi mobile 不是 [pi](https://pi.dev) 官方產品，與 Earendil 沒有關聯，也沒有經過他們背書。問題請回報到這個 repo。

## 下載
- **手機**：已經裝了 0.9.1 以後的版本，到設定頁最下面按「更新到 0.11.3」就好。也可以下載 `pi-mobile-0.11.3.apk` 手動安裝，**Android 16 以上**、arm64 手機；用同一把金鑰簽章，可以直接覆蓋安裝，保留現有資料。
- **電腦**：跟 0.10.0 一樣，沒有變。還沒更新到 0.10.0 的話：
  ```sh
  curl -fsSL https://raw.githubusercontent.com/geminixiang/pi-mobile/main/host/install.sh | sh
  ```

## 這一版有什麼
- **只給一個值也收**：要清單的參數只給一個值，例如台股代號寫 `"2330"` 沒包成陣列，現在直接接受。
- **「我附近」**：找地點時把位置填成 `true`，當成沒填，用手機目前的位置。
- **bash 找得到剛寫的檔案**：在資料夾寫了 `todo.md`，bash 有時會去別的路徑找。現在模型知道 bash 從資料夾開始，「建立 todo.md 再數行數」從 5 次來回減到 2 次。

## 要注意
- **0.9.0 以前的版本**：還沒有 App 內更新，要先手動裝一次 0.9.1 或這一版。
- **手機畫面**：更新 app 後，Android 會把無障礙服務關掉，要到 設定 › 手機 › 手機畫面 再開一次。
