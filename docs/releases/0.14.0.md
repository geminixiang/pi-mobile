pi mobile 0.14.0：「連接的服務」整頁改版；Bot 每次請求少帶一大段用不到的內容，回得更省；代你操作 App 的規則更清楚，也更安全。

> **非官方社群專案**：pi mobile 不是 [pi](https://pi.dev) 官方產品，與 Earendil 沒有關聯，也沒有經過他們背書。問題請回報到這個 repo。

## 下載
- **手機**：已經裝了 0.9.1 以後的版本，到設定頁最下面按「更新到 0.14.0」就好。也可以下載 `pi-mobile-0.14.0.apk` 手動安裝，**Android 16 以上**、arm64 手機；用同一把金鑰簽章，可以直接覆蓋安裝，保留現有資料。
- **iPhone**：從 TestFlight 更新。
- **電腦**：跟 0.10.0 一樣，沒有變。還沒更新到 0.10.0 的話：
  ```sh
  curl -fsSL https://github.com/geminixiang/pi-mobile/releases/latest/download/install.sh | sh
  ```

## 這一版有什麼
- **連接的服務改版**：每個服務有自己的圖示和一句它是做什麼的，右邊是正在使用它的 Bot。還沒登入的服務排成一格一格，點一下就登入；點一個服務看細節或移除它。要讓哪個 Bot 使用哪個服務，到那個 Bot 的面板 › 工具 打開。
- **Bot 沒有數量上限**：頭像用完後，新的 Bot 會拿到最少人用的那個。
- **代你操作 App**：原本的「手機畫面」開關改名為「代你操作 App」。只有開了它的 Bot 會替你點畫面，也只有它能在 pi 在背景時打開其他 App（例如做到一半打開地圖）。
- **擋下危險網頁**：憑證有問題、或被 Google 安全瀏覽標為危險的網頁，pi 的瀏覽器和讀網頁都會擋下，並告訴 Bot 原因。
- **顯示設定**：「顯示思考過程」和「預設展開工具輸出」從各 Bot 的面板移到 設定 › 顯示，一次套用到所有 Bot。

## 修正
- **Bot 每次請求帶了刪掉的 Bot 名單**：刪過很多 Bot 的話，每次請求都會帶上它們的名字和工作說明（我們的測試手機上約 300 個）。現在只列還在的 Bot 的名字，請求變小、也更省。刪 Bot 時電腦沒開，也不會再卡在刪到一半。
- **事項超過每日次數時一直被叫醒**：當天次數用完時，事項改到明天同一時間，並在那個 Bot 的對話裡說明，不再每 5 秒試一次耗電。
- **排程跑完後的背景服務**：排程執行失敗時，也會放掉為它保持手機清醒的背景服務。
- **MCP 服務蓋掉內建工具**：服務的工具和內建工具同名時不再取代它，「連接的服務」裡會註明。
- **第一次設定存檔失敗**：錯誤會顯示在標題下面，不再直接消失。
- **畫面出錯時**：改成顯示錯誤頁，不再一片空白。

## 要注意
- **服務的使用權移到 Bot 面板**：「連接的服務」頁不再有每個 Bot 的開關，已經給過的權限照舊。
- **0.9.0 以前的版本**：還沒有 App 內更新，要先手動裝一次 0.9.1 或這一版。
- **代你操作 App**：更新 app 後，Android 會把無障礙服務關掉，要到 設定 › 手機 › 代你操作 App 再開一次。
