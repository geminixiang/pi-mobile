pi mobile 0.5.0：手機資料夾也能用 git 與 GitHub，左右側欄展開後不再被繼續拉過頭。

> **非官方社群專案**：pi mobile 不是 [pi](https://pi.dev) 官方產品，與 Earendil 沒有關聯，也沒有經過他們背書。問題請回報到這個 repo。

## 下載
- **手機**：`pi-mobile-0.5.0.apk`，Android 7.0 以上、arm64 手機。用同一把金鑰簽章，可以直接覆蓋安裝 0.4.2，保留現有資料。
- **電腦**（選用，macOS 或 Linux，要裝好 Tailscale）：
  ```sh
  curl -fsSL https://raw.githubusercontent.com/geminixiang/pi-mobile/main/host/install.sh | sh
  ```
  已經裝過的話，跑同一行就會更新。

## 這一版有什麼
- **手機上的 git**：Bot 不必連接電腦，就能在自己的手機資料夾 clone GitHub repo、修改檔案、commit 與 push。
- **手機上的 GitHub 操作**：資料夾的 bash 加入 `gh` 常用指令子集，包括 API、PR、issue、repo 與登入狀態查詢，也能跨 repo 搜尋 issues 和 PRs。
- **側欄停在邊界**：左、右側欄完全展開後，不再往同一方向多滑一段。開啟途中拉過頭、拉到一半反向，以及正常滑回關閉，都在 S24 上驗證過。

## 要注意
- 手機資料夾的 git／gh 網路請求只允許 GitHub 相關 HTTPS 主機，不是任意主機的 Git client。
- 私有 repo 與寫入操作需要在設定提供具備相應權限的 GitHub token；憑證由主執行緒加入請求，不放進 bash 的環境、檔案或 git config。
- `gh` 是 app 支援的子集，不是完整的 GitHub CLI。
