pi mobile 0.3.0：排程變成「自動化」，更多手機上的事件能啟動 Bot；Bot 能做出網頁給你看；串流在 120 Hz 的手機上順多了。

> **非官方社群專案**：pi mobile 不是 [pi](https://pi.dev) 官方產品，與 Earendil 沒有關聯，也沒有經過他們背書。問題請回報到這個 repo。

## 下載
- **手機**：`pi-mobile-0.3.0.apk`，Android 7.0 以上、arm64 手機。用同一把金鑰簽章，可以直接覆蓋安裝 0.2.0。
- **電腦**（選用，macOS 或 Linux，要裝好 Tailscale）：
  ```sh
  curl -fsSL https://raw.githubusercontent.com/geminixiang/pi-mobile/main/host/install.sh | sh
  ```
  已經裝過的話，跑同一行就會更新。

## 這一版有什麼
- **自動化**：排程改叫自動化，每一項前面有圖示，表示是什麼啟動它。除了時間、耳機、充電、Wi‑Fi、地點，現在也能在這些時候執行：
  - 解鎖手機、電量低、換時區
  - 拍了新照片（可以只看某個相簿）
  - 連上或斷開某個藍牙裝置，例如車子
  - 開始或停止走路、跑步、騎車、搭車、靜止
  - 收到其他 app 的通知
- **網頁**：想看一個整理好的東西或要傳出去時，Bot 會寫成一個獨立的 .html。App 裡可以直接預覽（不能連網、碰不到 app 的資料），每個檔案都能用分享選單傳出去。
- **更順**：在 S24（120 Hz）上量：
  - 串流時超時的幀從 61% 降到 9%：字不再逐字淡入。
  - 送出訊息和回答完成時，不再卡一下（約 0.2 秒）。
  - 頂欄和輸入框改成實色，不再是毛玻璃：串流時一邊捲動，超時的幀從 19% 降到 12%。
- **手機資料夾的 bash** 更接近真的 bash：修正了會給出錯誤答案的地方，大檔案（兩百萬行）和慢的 awk 也能處理。
- **比較穩**：刪除 Bot 會先停下它的工作；移除 MCP 服務會從每個 Bot 收回；一個事件只會送到對話一次；電腦被移除的 Bot 不會自己搬到別台電腦。
- 開關一律是滑動開關，多選一一律是分段按鈕。
- APK 從 12.7 MB 變成 10.2 MB。

## 要注意
- **從 0.1.0 升級要先裝 0.2.0**：0.3.0 不再讀 0.1.0 的舊資料庫和設定。
- **Bot 做事不會先問你**：自動化觸發時也一樣。只給 Bot 你放心讓它用的工具和權限，見[安全模型](https://github.com/geminixiang/pi-mobile/blob/main/docs/security.md)。
- 活動辨識（走路、騎車等）要 Google Play 服務；照片和藍牙的自動化第一次建立時會要權限。
