pi mobile 0.19.0：一個 Bot 能指揮每台電腦上的 coding agent；電腦斷線後會自己接回來；Bot 會直接打開對的 App、記住怎麼用；新的外觀，更安靜、更省電；iPhone 開始有 TestFlight 公開測試。

> **非官方社群專案**：pi mobile 不是 [pi](https://pi.dev) 官方產品，與 Earendil 沒有關聯，也沒有經過他們背書。問題請回報到這個 repo。

## 下載
- **手機**：已經裝了 0.9.1 以後的版本，到設定頁最下面按「更新到 0.19.0」就好。也可以下載 `pi-mobile-0.19.0.apk`（或永遠指向最新版的 `pi-mobile.apk`）手動安裝。需要 **Android 16 以上**、arm64 手機。安裝檔用同一把金鑰簽章，可以直接覆蓋安裝，保留現有資料。
- **iPhone、iPad**：從 TestFlight 更新；還沒加入的，點 README 的 TestFlight 按鈕加入公開測試。
- **電腦**：**要更新**，斷線重接的修正在電腦端。Mac、Linux 在終端機再跑一次安裝指令；Windows 在 PowerShell 再跑一次。

## 這一版有什麼
- **一個 Bot 指揮每台電腦上的 agent**：以前 Bot 只看得到它所在那台電腦上的 Claude Code、Codex、pi。現在所有配對過的電腦一起列出來，你說「跟 pi-linux 那個說先停」，Bot 自己找到它在哪台。
  - 清單用你在 Rex 取的視窗名稱，跑完很久的背景指令不再列出來。
  - 有兩個都符合時，Bot 會跳選項讓你點，不會亂猜。
  - 某台電腦關機或連不到，只會少那一台，不會整個卡住。
- **Bot 會直接打開對的 App**：交代「看一下包裹到哪了」這類事，Bot 會從你手機上裝的 App 裡找對的那個直接打開，並且為每個 App 記下自己的使用筆記，下次更快。
  - 可以用元件的編號點、打字，不用靠座標；也能一次做完「捲到、等它出現、確認」。
  - iPhone 上，點不到被 Safari 放大到畫面外的網頁元素、鍵盤擋住欄位這類問題也修好了。
- **跟錢有關的，一定問你**：代你操作 App 時，只要畫面上出現金額，每一步都先問你；這個判斷寫在 App 裡，不交給模型。要送出你沒有明講的內容時，會等你按「送出這次」。
- **Bot 把你的做法存成 skill**：你教 Bot 怎麼做一件事，它可以存成自己的 skill，之後照著做。
- **新的外觀**：回答改用無襯線字、段落更好讀；引言、表格、程式碼改用淡淡的陰影，不再畫外框；圓角統一。
- **更安靜、更省電**：Bot 在做事時，頭像右下角亮一個**不動**的黃點；整個 App 沒有任何會一直閃的東西，畫面閒著時不會叫醒 GPU。
- **串流更順**：你往上看舊訊息時，正在寫的回答不會一直搶畫面；畫面外的回答不重畫。在 S24 上，串流中捲動掉的幀從約 12% 降到約 2%。
- **iPhone**：瀏覽器也能在 iPhone 上用，網頁差事在 pi 自己的瀏覽器裡跑。

## 修正
- **電腦斷線後要重開 pi 才會好**：Tailscale 斷掉超過 15 分鐘再連回來，連到那台電腦的 Bot 會一直卡住，只能重開 pi。現在會自己重新接上；連不上時 20 秒內告訴你，不會卡住。電腦端也不再累積沒關掉的連線。
- **手機關機時錯過的每日排程**：開機後補跑一次，Bot 也知道它晚了。
- **停止背景工作會叫醒 Bot**：已修正。
- **中文名字的登入資訊變亂碼**：已修正。
- **儲存某些設定會讓整個 runtime 重開**：已修正。

## 要注意
- **代你操作 App**：更新 App 後，Android 會把無障礙服務關掉，要到 設定 › 手機 › 代你操作 App 再開一次。
- **電腦要一起更新**：斷線重接的修正，一半在電腦端。
- **背景螢幕**（Bot 在看不到的螢幕上操作 App）只在開源版，這個安裝檔沒有。
