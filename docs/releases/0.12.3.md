pi mobile 0.12.3：Bot 在網頁打字時不再跳出鍵盤，長按標題不會選到文字，設定頁每次打開都會檢查新版。

## 下載
- **手機**：已經裝了 0.9.1 以後的版本，到設定頁最下面按「更新到 0.12.3」就好。也可以下載 `pi-mobile-0.12.3.apk` 手動安裝，**Android 16 以上**、arm64 手機；用同一把金鑰簽章，可以直接覆蓋安裝，保留現有資料。
- **iPhone**：從 TestFlight 更新。
- **電腦**：跟 0.10.0 一樣，沒有變。還沒更新到 0.10.0 的話：
  ```sh
  curl -fsSL https://raw.githubusercontent.com/geminixiang/pi-mobile/main/host/install.sh | sh
  ```

## 修正
- **Bot 打字不再跳出鍵盤**：瀏覽器開著時，Bot 點進網頁欄位打字，鍵盤不會再跳出來把瀏覽器擠扁。你自己點網頁欄位或對話框，鍵盤照常出現。
- **介面文字不會被選取**：長按面板標題或其他標籤不會再留下選取，左右滑動也不會因此失效。訊息、程式碼和輸入框仍然可以選取複製。
- **設定頁會重新檢查新版**：以前 pi 開著很久不會發現新版本，現在每次打開設定都會重新檢查。

## 要注意
- **0.9.0 以前的版本**：還沒有 App 內更新，要先手動裝一次 0.9.1 或這一版。
- **手機畫面**：更新 app 後，Android 會把無障礙服務關掉，要到 設定 › 手機 › 手機畫面 再開一次。
