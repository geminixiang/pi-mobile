pi mobile 0.11.4：在手機資料夾 clone 大的 repo 不再讓 app 閃退；iPhone 也能問步數。

> **非官方社群專案**：pi mobile 不是 [pi](https://pi.dev) 官方產品，與 Earendil 沒有關聯，也沒有經過他們背書。問題請回報到這個 repo。

## 下載
- **手機**：已經裝了 0.9.1 以後的版本，到設定頁最下面按「更新到 0.11.4」就好。也可以下載 `pi-mobile-0.11.4.apk` 手動安裝，**Android 16 以上**、arm64 手機；用同一把金鑰簽章，可以直接覆蓋安裝，保留現有資料。
- **iPhone**：從 TestFlight 更新。
- **電腦**：跟 0.10.0 一樣，沒有變。還沒更新到 0.10.0 的話：
  ```sh
  curl -fsSL https://raw.githubusercontent.com/geminixiang/pi-mobile/main/host/install.sh | sh
  ```

## 修正
- **clone 大的 repo 不再閃退**：在手機資料夾 `git clone` 一個幾十 MB 的 repo，之後每個 git 指令都會讓 app 閃退（「Pi 屢次停止運作」），Bot 只看到指令被中斷，就一直換指令重試。現在大檔分段讀，clone 之後 `log`、`status`、`git grep` 都正常。
- **記帳更順**：模型把 SQL 直接寫成文字、沒有照格式包好時，現在直接執行，不用再錯一次重寫。

## 這一版有什麼
- **iPhone 讀得到步數**：問「今天走了幾步」「這週每天走幾步」，iPhone 上也答得出來，最多最近 7 天。睡眠、心率這些還讀不到，Bot 會直接說。

## 要注意
- **0.9.0 以前的版本**：還沒有 App 內更新，要先手動裝一次 0.9.1 或這一版。
- **手機畫面**：更新 app 後，Android 會把無障礙服務關掉，要到 設定 › 手機 › 手機畫面 再開一次。
