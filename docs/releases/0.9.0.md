pi mobile 0.9.0：Bot 能查台股盤後資料、照技能做個股分析，市集多了美股和台股的資料服務；電腦上的第一個指令從約 20 秒變成約 1 秒；電腦端修好斷線和配對的幾個問題。

> **非官方社群專案**：pi mobile 不是 [pi](https://pi.dev) 官方產品，與 Earendil 沒有關聯，也沒有經過他們背書。問題請回報到這個 repo。

## 下載
- **手機**：`pi-mobile-0.9.0.apk`，**Android 16 以上**、arm64 手機。用同一把金鑰簽章，可以直接覆蓋安裝 0.8.0，保留現有資料。
- **電腦**（選用，macOS 或 Linux，要裝好 Tailscale）：
  ```sh
  curl -fsSL https://raw.githubusercontent.com/geminixiang/pi-mobile/main/host/install.sh | sh
  ```
  已經裝過的話，跑同一行就會更新；配對和權限都保留，不用重新配對。

## 這一版有什麼
- **台股**：新工具組「台股」，資料來自證交所和櫃買中心的盤後資料：上市櫃的每日股價、三大法人買賣超、融資融券、本益比／股價淨值比／殖利率、最新月營收，以及大盤（加權、櫃買指數、成交值、三大法人金額）。
  - 新技能「stock-analysis」：台股的慣例和資料公布時間、哪個問題查哪份資料、用腳本算均線和籌碼，回答不給買賣建議；也教 Bot 怎麼建「每天收盤後整理自選股」的排程。
  - 沒給日期時往前找最近有資料的交易日，遇到休市會說休市。
- **市集多兩個股市服務**（不用登入）：
  - **Shibui Finance**：美股，1962 年起的每日股價、季報年報、估值、SEC 申報、內部人交易。每段新對話第一次問，Bot 要先讀資料表結構，多花約 2 萬 tokens。
  - **台股開放資料**（非官方）：證交所 OpenAPI 和期交所資料，上市櫃盤中報價約 5 秒更新。
- **電腦上的第一個指令快很多**：以前第一次在電腦上跑指令要先在手機上解開並驗證 pi-env，約 20 秒；現在只在電腦上還沒有那個版本時才做，約 1 秒就開始。
- **電腦端的修正**（要電腦端也更新到 0.9.0）：
  - 從手機「移除」電腦時，0.8.0 的電腦端會擋掉手機的撤銷請求，配對其實還留在電腦上；0.9.0 會真的撤銷，並結束那支手機在電腦上留著的指令。
  - 手機斷網時電腦等著手機回來的指令，現在只認開它的那支手機；其他已配對的手機接不回、也頂不掉它。
  - 網路掉時，電腦送給手機的資料最多等 10 秒，送不出去就當斷線、開始等手機回來；以前會卡住，連帶讓 pi-env 30 秒後自己結束，指令就斷了。
  - 手機刻意關掉的連線，電腦立刻收掉那個指令，不再等 5 分鐘。
- **手機上的原生功能**：
  - 讀聯絡人、通話紀錄、簡訊、行事曆、使用時間、通知改在背景執行緒，不會擋住其他原生呼叫；資料庫和相片搜尋出錯時，工具會回錯誤，不會一直等下去。
  - 原生功能回傳的資料都會先對照格式檢查，不符就回明確的錯誤。手機沒有某個原生功能時，用到它的工具和工具組不會出現。
- **其他**：
  - 新建的 sandbox 改用 Node.js 26，pnpm 改用 npm 安裝，wrangler、cf、uv 也更新到新版；對外連線的 proxy 更新到 mitmproxy 12.3.1。
  - 電腦端用 Go 1.27.3 建置。
  - App 改用 Android Gradle Plugin 9 和 compileSdk 37 建置；掃描文件的文字辨識照常可用。
  - MCP 服務登入完成後，不再留著接收登入結果的本機連接埠。

## 要注意
- **電腦端也要更新**：上面電腦端的修正，要電腦端也是 0.9.0 才有。0.8.0 的電腦端配 0.9.0 的手機可以用，但從手機移除電腦時不會撤銷配對。
- **第一次用到容器會比較久**：對外連線的 proxy 映像換了版本，更新後 Bot 第一次用到容器時會先重建它，要等幾分鐘。
- **已經建好的 sandbox 還是 Node.js 24**：已經存在的 sandbox 容器會繼續沿用，不會換成新映像，裡面還是 Node.js 24，也還有 yarn；新建的容器才是 Node.js 26，而且沒有 yarn（Node.js 26 不再附帶 corepack，只剩 npm 和 pnpm）。Bot 的說明寫的是 Node.js 26，在舊容器裡用 `node --version` 才準。
- **手機畫面**：更新 app 後，Android 會把無障礙服務關掉，要到 設定 › 手機 › 手機畫面 再開一次。
