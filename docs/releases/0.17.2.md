pi mobile 0.17.2：手機和電腦的連線斷一下，交辦的工作和電腦畫面的操作也會完整做完，不會只做一半、再做一次。

> **非官方社群專案**：pi mobile 不是 [pi](https://pi.dev) 官方產品，與 Earendil 沒有關聯，也沒有經過他們背書。問題請回報到這個 repo。

## 下載
- **手機**：已經裝了 0.9.1 以後的版本，到設定頁最下面按「更新到 0.17.2」就好。也可以下載 `pi-mobile-0.17.2.apk` 手動安裝，**Android 16 以上**、arm64 手機；用同一把金鑰簽章，可以直接覆蓋安裝，保留現有資料。
- **iPhone**：從 TestFlight 更新。
- **電腦**：不用更新。

## 修正
- **交辦給電腦上的 agent 不會變成兩份**：以前送出任務的瞬間網路一斷，任務可能只貼進 agent 的輸入框、沒按 Enter，Bot 再送一次就變成兩份黏在一起；現在電腦會把它送完，Bot 重新連上後就知道送到了。
- **電腦畫面的操作不會做一半**：Bot 在電腦上打字、點擊時連線斷掉，以前剩下的步驟就不做了，Bot 再做一次會把字打兩遍；現在電腦會做完，Bot 拿到的是做完的畫面。
- **電腦連線更穩**：切換網路時不會重複連線，電腦真的準備好了才顯示已連線。
- **停掉憑證橋接更確實**：容器模式在橋接還在啟動時被停掉，以前它會留著舊的憑證繼續跑；現在會一起停掉。

## 要注意
- **代你操作 App**：更新 app 後，Android 會把無障礙服務關掉，要到 設定 › 手機 › 代你操作 App 再開一次。
