pi mobile 0.16.0：第一次打開就能用 ChatGPT 登入，新 Bot 會主動幫你找第一件事；背景換成晨光紙紋；修掉一個會讓 App 當掉的問題和好幾個會卡住的情況。

> **非官方社群專案**：pi mobile 不是 [pi](https://pi.dev) 官方產品，與 Earendil 沒有關聯，也沒有經過他們背書。問題請回報到這個 repo。

## 下載
- **手機**：已經裝了 0.9.1 以後的版本，到設定頁最下面按「更新到 0.16.0」就好。也可以下載 `pi-mobile-0.16.0.apk` 手動安裝，**Android 16 以上**、arm64 手機；用同一把金鑰簽章，可以直接覆蓋安裝，保留現有資料。
- **iPhone**：從 TestFlight 更新。
- **電腦**：不用更新。

## 這一版有什麼
- **第一次打開**：第一頁只有「用 ChatGPT 登入」，登入完直接開始；有 API key 的話點下面那行。
- **新 Bot 先開口**：新 Bot 會打招呼，按「建議第一個任務」，它會看你的行事曆和通知，找幾件能幫忙的事，問你要從哪件開始。只讀，不會改任何東西。
- **新背景**：格線換成帶細紙紋的晨光漸層，左上一點暖光、右下一點藍，深色模式也有。
- **工作時只有一行**：Bot 做事時對話裡只顯示這件事的名字，步驟收起來，要看才展開。動手前先說一句，做完會說沒做到什麼、查不到什麼。
- **對話裡的卡片**：天氣、Bot 做的頁面都變成卡片；第一次用到手機權限時先有一張卡說明用途，按了才跳系統視窗；服務要求確認才寄出的動作也是一張卡。
- **瀏覽器更快**：Bot 用腳本一次操作瀏覽器，一樣的工作步驟和花費都少很多，截圖還是看得到。

## 修正
- **第一次送出就當掉**：回合很快結束時（例如金鑰錯誤），App 可能直接關閉。
- **送出後什麼都沒發生**：沒有可用的模型時，現在會在對話尾端說明原因。
- **自訂端點**：網址沒填不能開始；API key 真的可以不填。
- **切換 Bot 跳出鍵盤**：建立過 Bot 之後，每次切換都會跳鍵盤。
- **ChatGPT 登入卡住**：沒登入就回來時，現在可以取消。
- **網頁卡死拖垮 App**：有問題的網頁不會再讓 pi 整個卡住；pi 自己沒回應時也會自動恢復，對話接著跑。
- **iPhone**：不再出現「工作中」的橫幅和失敗通知；鎖定時斷掉的回答會重試。
- **連接的服務**：網址沒有路徑的服務（例如 Stripe、Vercel）登得進去了；服務端重啟後會自動重新連線。
- **排程**：錯過的鬧鐘只補跑一次；到期的待辦不會被漏掉；一筆讀不了的舊排程不會擋住其他排程。
- **大約位置**：只給大約位置時，不用再等 20 秒。
- **連電腦失敗**：現在看得到真正的原因。

## 要注意
- **手機資料夾的 `gh`**：只留 `gh api` 和 `gh auth status`；`git diff --check` 也拿掉了。Bot 會改用其他方式。
- **精確鬧鐘權限**：系統設定裡的「鬧鐘與提醒」項目不見了，排程一樣準時。
- **0.9.0 以前的版本**：還沒有 App 內更新，要先手動裝一次 0.9.1 或這一版。
- **代你操作 App**：更新 app 後，Android 會把無障礙服務關掉，要到 設定 › 手機 › 代你操作 App 再開一次。
