## 下載
- **手機**：已經裝了 0.9.1 以後的版本，到設定頁最下面按「更新到 0.10.1」就好。也可以下載 `pi-mobile-0.10.1.apk` 手動安裝，**Android 16 以上**、arm64 手機；用同一把金鑰簽章，可以直接覆蓋安裝，保留現有資料。
- **電腦**：跟 0.10.0 一樣，沒有變。還沒更新到 0.10.0 的話：
  ```sh
  curl -fsSL https://raw.githubusercontent.com/geminixiang/pi-mobile/main/host/install.sh | sh
  ```

## 這一版有什麼
- **右側欄**：左右邊距一樣寬，打開時從右邊緣放大出來，內容不再往對話那邊靠。
- **少一點說明文字**：
  - 工具輸出摺起來時只寫「… 前面 N 行」，不再加「點一下展開」。
  - 長按捲動鈕選訊息時，停在「最新」不再顯示操作說明。
  - 設定 › 連接的服務：「瀏覽服務」改成一顆按鈕。
- **程式碼整理**：六輪簡化，刪掉只用一次的小元件和函式、沒有作用的樣式和檢查；改用 React 19、pi-ai、chord 和瀏覽器已經提供的寫法。工具的名稱、參數和輸出都沒變。在 Galaxy S24 上量過捲動、串流、打字和側欄，前後在誤差內。

## 要注意
- **0.9.0 以前的版本**：還沒有 App 內更新，要先手動裝一次 0.9.1 或這一版。
- **手機畫面**：更新 app 後，Android 會把無障礙服務關掉，要到 設定 › 手機 › 手機畫面 再開一次。
